## 四、你的核心竞争力定位（6年经验）

大厂看你不只看“会不会写代码”，更看：

1. 能否主导复杂模块（架构、拆分、落地）
2. 能否解决性能/稳定性问题（有真实战例）
3. 能否跨团队推进（协作、影响力）
4. 能否建立工程规范（质量、监控、发布）

你所有回答都尽量往这四点靠。

## 五、加强回答统一框架（推荐）

技术题统一用：

- **定义**（是什么）
- **原理**（为什么）
- **取舍**（优缺点）
- **场景**（什么时候用）
- **实战**（你做过什么）

项目题统一用：

- **背景** → **目标** → **方案** → **落地细节** → **结果数据** → **复盘与优化**

这会让你的表达非常“高级工程师化”。
