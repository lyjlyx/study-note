## JVM 运行时数据区总结（你的版本）

JVM 运行时数据区分线程私有和线程共享。线程私有有程序计数器、虚拟机栈、本地方法栈；线程共享有堆和方法区。
程序计数器记录当前线程字节码执行位置；虚拟机栈按方法调用维护栈帧。
堆是对象分配和垃圾回收核心区域；方法区存类元信息和运行时常量池，JDK8 后由 Metaspace 实现，使用本地内存。
常见异常方面，栈可能 StackOverflowError，堆可能 Java heap space，方法区可能 Metaspace OOM。

## JVM 栈帧如何执行字节码（局部变量表 + 操作数栈）

- 每次方法调用都会创建一个栈帧并压入虚拟机栈，方法结束后弹出。
- 栈帧的核心结构：局部变量表、操作数栈、动态链接、方法返回地址。

### 1）局部变量表（Local Variable Table）
- 按 **slot** 存储参数与局部变量。
- long/double 占 2 个 slot，其余一般占 1 个。
- 实例方法中 slot0 通常是 	his；后面依次是方法参数和局部变量。

### 2）操作数栈（Operand Stack）
- 字节码执行时的“临时计算栈”。
- 指令通常遵循“入栈 -> 运算 -> 出栈/写回”的模式。

### 3）执行流程（以 int c = a + b 为例）
- 从局部变量表把 、 加载到操作数栈（如 iload_1, iload_2）。
- 执行加法指令（iadd），弹出两个操作数并压回结果。
- 用 istore_3 把结果写回局部变量表中的 c。
- 最终通过 ireturn 或 eturn 完成方法返回。

### 4）你面试可直接说的重点
- 局部变量表负责“存”，操作数栈负责“算”。
- 字节码是栈机器指令集，很多指令围绕操作数栈进行。
- 这套模型让 JVM 可移植（统一字节码语义），由不同平台 JVM 解释/JIT 编译执行。
