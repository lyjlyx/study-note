### 何为常数时间的操作？

**如果一个操作的执行时间不以具体样本量为转移，每次执行时间都是固定的事件。称这样的操作为常数时间的操作。**（数组的寻址就是一个固定时间的操作，他的执行时间不会随你的样本量变大而发生改变）

![image-20250809091309487](https://lyx-study-note-image.oss-cn-shenzhen.aliyuncs.com/img/image-20250809091309487.png)

**总之，执行时间固定的操作都是常数时间的操作**

**反之，执行时间不固定的操作，都不是常数时间的操作**



![image-20250809092340500](https://lyx-study-note-image.oss-cn-shenzhen.aliyuncs.com/img/image-20250809092340500.png)

**时间复杂度表达式的列式会忽略掉低阶项和系数所剩下来的东西就是时间复杂度。**

**最终都是要把低阶项和系数抹掉的。**

![image-20250809092552416](https://lyx-study-note-image.oss-cn-shenzhen.aliyuncs.com/img/image-20250809092552416.png)

**我们只要确保流程划分的过程中都是常数级别的操作，不用严格精细的纠结他发生了多少次，只要我们保证他是常数级别的操作就够了，因为最终的时间复杂度是不看低阶项也不要高阶项的系数留下来的东西，这就是时间复杂度。**

### 如何确定算法流程的时间复杂度

**当完成了表达式的建立，只要吧最高阶项留下即可。低阶项都去掉，高阶项的系数也去掉。**

**记为：O(忽略掉系数的高阶项)**



**当我们样本量大到一定程度，或者足够大的时候，我们会发现低阶项是什么高阶项的系数是什么都变得不再重要了。**

**衡量算法流程的复杂程度的一种指标。**



选择排序、冒泡排序、插入排序的时间复杂度都是O(N²)

选择排序：0~N-1范围最小值交换，1~N-1范围最小值交换，2~N-1范围最小值交换......

冒泡排序：0~N 之间 0和1谁大谁交换，1和2谁大谁交换，2和3谁大谁交换....到最后就是最大的值后面的数就搞定了。再就是0~N-1之间的数谁大谁交换。

插入排序：0~0范围之间的数保证有序，0~1范围之间保证有序，0~2范围之间保证有序，从右往左谁小谁交换，往左移动，一路往前换直到最左边没有数了。



**要拿最差的例子得出时间复杂度**



**算法的过程，和具体的语言是无关的**

**想分析一个算法流程的时间复杂度的前提，是对该流程非常熟悉**

**一定要确保在拆分算法流程的时候，拆分出来的所有行为都是常数时间的操作。这意味着你写算法的时候对自己用过的每一个系统API，都非常的熟悉，否则会影响你对时间复杂度的估算。**



### 额外空间复杂度

**常数操作就是时间复杂度为O(1)的操作**



你要实现一个算法流程，在实现算法流程的过程中，你需要开辟一些空间来支持你的算法流程。

作为输入参数的空间，不算额外空间。

作为输出结果的空间，也不算额外空间。

因为这些都是必要的、和现实目标有关的，所以都不算。

但除此之外，你流程如果还需要开辟空间才能让你的流程继续下去，这部分空间就是额外空间。

如果你的流程只需要开辟有限几个变量，额外空间复杂度就是0(1)



### 算法流程的常数项的比拼方式

**放弃理论分析，生成随机数据直接测试**

为什么不去理论？

不是不能纯分析，而是没有必要。因为不同常数时间的操作，虽然都是固定时间，但还是有快慢之分的。

比如，位运算的常数时间远小于算数运算的常数时间，这两个运算的常数时间又远小于数组寻址的时间。

所以如果纯理论分析，往往会需要非常多的分析过程。都已经到了具体细节的程度，莫不如交给实验数据好了。

### 局部最小值

**什么叫做局部最小值**

1、位置的数如果比1位置的数小，他就是局部最小

2、N位置的数如果比N-1位置的数小，他就叫做局部最小

3、i -1  i  i + 1  i位置的数既比i-1位置的数小，又比i + 1位置的数小，i位置的数据就是局部最小



arr无序数组，这个数组中任意两个相邻的数都不相等，只要求范围一个局部最小的数返回就行，随便哪一个就行。

可以使用二分法。

arr[ 0 ~ N -1 ] 无序，相邻不等

思路：先看0 位置的数是否比1位置的数大，如果是的话他就不是局部最小，他的趋势是一个向下的↓

再看N-1位置的数是否比N-2位置的数大，如果N-1位置的数更大，那他的趋势是向上的↑

![image-20250818165009554](https://lyx-study-note-image.oss-cn-shenzhen.aliyuncs.com/img/image-20250818165009554.png)

综上所述：**中间必有局部最小值**

我们使用mid标记，从中间开始找

mid - 1 |  mid | mid  + 1 如果 mid比他-1和+1的位置都小的话直接返回mid位置的数，mid就是局部最小的数。



**只要我们构建出一个排掉另外一测的逻辑，而且这个逻辑是正确的，其实就可以使用二分法**



### 认识异或运算

异或运算：相同为0，不同为1

同或运算：相同为1，不同为0

**所以，异或运算就记成无进位相加！**

异或运算的性质

1）0^N == N    N^N == 0

2）异或运算满足交换律和结合率（不用管a,b,c,d,e是什么顺序，只要是同一批数异或起来的东西都是一样的）

上面两个性质用无进位相加来理解就非常的容易。

#### 一个数组中有两种数出现了奇数次，其他的数都出现了偶数次，怎么找到这两种数

**先把eor异或上所有的数，因为偶数次相同的数异或在一起都是0，而a、b是出现了奇数次的数，所以最后的结果一定是a^b，最终a^b最终的结果就是eor，因为说的是两种数出现了奇数次，所以a、b一定不等，他们两不等就意为这eor一定是有数的，我们假设：第八位是不一样的，那他的第八位一定是1，所以就是a的第八位一定不等于b的第八位。**

我们在准备一个变量eor2，这个eor2只异或第八位是1的数，不去操作第八位是0的数，这样就找到了eor2是a或者b，而另外一个就是eor^eor2，他就是另外一个。

```java
/**
     * 在arr中，有两种数出现了奇数次
     * @param arr
     */
    public static void printOddTimesNum2(int[] arr) {
        int eor = 0;
        for (int i = 0; i < arr.length; i++) {
            eor ^= arr[i];
        }
        // eor = a ^ b;
        // eor != 0
        // eor中必然会有一个位置上是1
        // 0110010000
        // 0000010000
        int rightOne = eor & (~eor + 1); // 取出最右侧的1
        int onlyOne = 0;// eor2
        for (int i = 0; i < arr.length; i++) {
            if ((arr[i] & rightOne) != 0) {
                onlyOne ^= arr[i];
            }
        }
        System.out.println(onlyOne + " " + (eor ^ onlyOne));
    }
```

```java
    public static Node reverseLinkedList(Node head) {
        // 前一个节点
        Node pre = null;
        // 下一个节点
        Node next;
        while (head != null) {
            // 先把头的下一个节点记住
            next = head.next;
            // 把头的下一个节点指向pre
            head.next = pre;
            pre = head;
            // 头为下一个节点的值
            head = next;
        }
        return pre;
    }
```

```java
public static Node removeValue(Node head, int value) {
        // 先遍历链表，找到第一个不是value的节点，他一定是最后的头部
        while (head != null) {
            if (head.value != value) {
                break;
            }
            head = head.next;
        }
        // 3->3->3->4->5->6->3->3->6->7
        // 这个时候head会来到第一个不需要删除的位置
        Node pre = head; //相当于上一个不等于value的值
        Node cur = head;
        while (cur != null) {
            if (cur.value == value) {
                pre.next = cur.next;
            } else {
                pre =cur;
            }
            cur = cur.next;
        }
        return pre;
    }
```

```java
        public class MyQueue {

            int[] arr;
            int pushli;
            int polli;
            int limit;
            int size;

                arr = new int[limit];
                pushli = 0;
                polli = 0;

             * 入队

             */
            public void push(int value) {
                if (size == limit) {
                    throw new RuntimeException("队列已满");
                }
                size ++;
                arr[pushli] = value;
                pushli = nextIndex(pushli);
            }


            /**
             * 出队
             * @return
             */
            public int poll() {
                if (size == 0) {
                    throw new RuntimeException("队列空了!");
                }
                size --;
                int ans = arr[polli];  // 1. 取出polli位置的元素
                polli = nextIndex(polli);  // 2. polli移动到下一个位置
                return ans;  // 3. 返回取出的元素
            }

            public int nextIndex(int i) {
                return i < limit - 1 ? i + 1 : 0;
            }
            


        }
```

分为data栈和min栈

![image-20260123220730379](https://lyx-study-note-image.oss-cn-shenzhen.aliyuncs.com/img/image-20260123220730379.png)

min栈是当前加入的数谁小加谁

弹出的时候两个栈一起弹出

push O(1)
poll O(1)

getMin

```java
public static class MyStack {
        private Stack<Integer> stackData;
        private Stack<Integer> stackMin;

        public MyStack() {
            this.stackData = new Stack<Integer>();
            this.stackMin = new Stack<Integer>();
        }

        public void push(int newNum) {
            //当前数和此时最小栈的栈顶谁小压谁
            if (stackData.isEmpty()) {
                stackData.push(newNum);
                stackMin.push(newNum);
            } else if (newNum < this.getMin()) {
                this.stackMin.push(newNum);
            } else {
                // 当前这个最小栈的栈顶更小，则重复压入这个数
                int newMin = stackMin.peek();
                stackMin.push(newMin);
            }
            // data栈无论如何都压
            stackData.push(newNum);
        }

        public int pop() {
            if (this.stackData.isEmpty()) {
                throw new RuntimeException("当前栈为空");
            }
            // 同步弹出，给用户data栈里的数
            stackMin.pop();
            return stackData.pop();
        }

        public int getMin() {
            if (this.stackMin.isEmpty()) {
                throw new RuntimeException("最小栈为空了");
            }
            return stackMin.peek();
        }
```

#### 如何用栈结构实现队列结构

两个栈一个是push栈一个是pop栈

其实就是需要数的时候从push栈出，在把push栈的数倒到pop栈中

1）从push栈到pop栈，pop必须为空的情况下才能倒进去。

2）push栈在倒的时候一定要一次性倒完

```java
public class TwoStacksImplementQueue {

    public static class TwoStacksQueue {

        public Stack<Integer> stackPush;
        public Stack<Integer> stackPop;

        public TwoStacksQueue() {
            stackPush = new Stack<>();
            stackPop = new Stack<>();
        }

        // push栈向pop栈倒入数据
        private void pushToPop() {
            if (stackPop.isEmpty()) {
                // 一定要倒空了才停止
                while (!stackPush.isEmpty()) {
                    stackPop.push(stackPush.pop());
                }
            }
        }

        public void add(int pushInt) {
            stackPush.push(pushInt);
            pushToPop();
        }

        public int poll() {
            if (stackPop.empty() && stackPush.isEmpty()) {
                throw new RuntimeException("Queue is Empty!");
            }
            pushToPop();
            return stackPop.pop();
        }

        public int peek() {
            if (stackPop.empty() && stackPush.isEmpty()) {
                throw new RuntimeException("Queue is Empty!");
            }
            pushToPop();
            return stackPop.peek();
        }


    }

}
```

#### 怎么从思想上理解递归

**例子：**求数组arr[L...R]中的最大值，怎么用递归方法实现

1）将[L...R]范围分成左右两半，左：[L...Mid] 右[Mid + 1 ..R]

2）左部分求最大值，右部分求最大值

3）[L..R]范围上的最大值是max{左部分最大值，右部分最大值}

注意：2）是个递归过程，当范围上只有一个数的时候，就可以不用再递归了。

```java
public class GetMax {

    public static int getMax(int[] arr) {
        return process(arr, 0, arr.length - 1);
    }

    public static int process(int[] arr, int L, int R) {
        if (L == R) {
            return arr[L];
        }
        // L..mid mid + 1 .. R
        // int mid = (L+R)/2
        // 用二分法
        int mid = L + ((R - L) >> 1);
        int leftMax = process(arr, L, mid);
        int rightMax = process(arr, mid + 1, R);
        return Math.max(leftMax, rightMax);
    }

}
```



**实际上其实就是把一件事情分解掉，把一件大事分解成一件小事，把每一件小事的答案求出来，再把每一件小事的答案通过自己的决策过程就能获取大事的答案。**

### Master公式

对于某一类递归行为，他的时间复杂度是可以确定的

T(N) = aT(N/b) + O(N^d)   a,b,d是常数

该公式描述了一个将规模为 N$的问题分解为多个子问题的递归过程：

- **T(N)**：解决规模为 N的问题所需的总时间。
- **a**：子问题的数量（每次递归产生的分支数）。
- **N/b**：每个子问题的规模（原问题的 1/b）。
- **O(N^d)**：**非递归部分**的工作量。这包括分解问题和合并子问题结果所需的代价。其中 d是该代价的幂次。



递归行为中子问题规模是N/b的规模，就符合上面的公式形式。如果每一次子问题的递归规模都是不一样的，那这个公式就用不了。如果子问题的规模都是等量小的情况下， 现在把这个子问题调用了a次，出去子问题调用之外的时间复杂度叫做O(N^d)。 只要满足这样形式的递归都可以用这个公式。

### 归并排序时间复杂度分析

选择、冒泡和插入 这些排序都是O(N^2)，而归并排序能够做到O(N*logN)

为什么O(N^2)不太好是因为他们都在大量的浪费比较行为

一直只做一件事，就是经过一轮一轮的比较都是指把一个数放到了左侧，都在大量的浪费比较行为，导致了N^2的出现
